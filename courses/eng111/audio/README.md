# صوتيات مقرر انجل-111

ضع هنا مقاطع الكتاب بصيغة mp3. اسم كل ملف: track- ثم رقم الوحدة وحرف الجزء ورقم التمرين وحرفه كما في الكتاب.
أمثلة: track-1A-1b.mp3 (الوحدة 1، الجزء A، التمرين 1b)، و track-R1-3.mp3 (المراجعة 1، التمرين 3).
اسم كل خانة مكتوب في الدرس بجانب كلمة «المقطع». إلى أن يُرفع الملف تظهر في خانته رسالة «لم يُرفع بعد».

مجلد tts/ فيه تسجيلات النطق لأزرار 🔊 (صوت Kokoro الأمريكي، مولّدة آلياً). لا تحذفه ولا تغيّر أسماء ملفاته.
